# drills/

Single-concept exercises. Small, disposable, heavily commented.

Each drill directory contains a `setup` script that builds its own environment
from scratch, an exercise sheet, and my `answers.md`. **The answers file is the
artifact** — the queries alone show nothing without the reasoning that produced
them.

Standing rule for every drill: predict the result before running the query.
The gap between prediction and result is the entire lesson.
